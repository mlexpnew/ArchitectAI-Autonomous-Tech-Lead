Project Name:
E-Commerce Management System

Overview:
The system manages customers, products, categories, shopping carts, orders, payments, and inventory. Customers can browse products, add items to their cart, place orders, and complete payments.

=========================================

- id : integer

- id : integer

Address
- id : integer

- state : string
- postal_code : string
- country : string

=========================================
Relationships
=========================================

A Customer can have many Addresses.

A Customer owns one Shopping Cart.

A Shopping Cart contains many Cart Items.

Each Cart Item belongs to one Product.

A Customer can place many Orders.

Each Order contains many Order Items.

Each Order Item belongs to one Product.

Each Order has one Payment.

Each Category contains many Products.

Validation Rules
=========================================

Email must be unique.

SKU must be unique.

Price must be greater than zero.

Stock quantity cannot be negative.

Order total must be greater than zero.

Payment amount must match order total.
